# Mapa de negocio

Dos skills que van juntas. **Radiografía:** Levy le hace al dueño las preguntas en orden y arma el mapa de su sistema
(marketing → venta → entrega → números) con el cuello de botella marcado, qué arreglar primero y cuánto le cuesta no
hacerlo. **Mapa vivo:** convierte esa Radiografía en una página del Lienzo con cuatro capítulos que se recorre como una
clase, para enseñárselo al dueño.

Pide la skill `canvas` de la base de Arbrain y `python3`. Escribe solo en `.claude/memory/project/clientes/` y
`.claude/memory/project/mi-negocio/` de tu cerebro. Pruebas: `python3 -m unittest discover -s skills/<skill>/tests`
desde tu carpeta de Arbrain.
